# Grasshopper author settings (template)

Set this once on every computer you use Grasshopper on. From then on, every
definition you save carries this author block inside the .gh file.

**Where:** in the Grasshopper window (not Rhino), File menu, then
Preferences (Ctrl+Shift+P), then the **Author** page on the left.

Copy each line into the matching field:

| Field | Value |
|---|---|
| Name | `Shafiul Islam` |
| Company | leave empty |
| Copyright | `© 2026 Shafiul Islam. Licensed CC BY 4.0. https://shafiarch.github.io/Grasshopper/` |
| Address | leave empty |
| Website | `https://shafiarch.github.io/Grasshopper/` |
| E-mail | optional: a personal address, never a work one (it is written into every shared file) |
| Phone | leave empty |

Close the window with the x; it saves on its own.

**Stamping existing files:** the setting only affects files saved after it is
set. To stamp an older definition, open it in Grasshopper, press Ctrl+S, and
upload it again.

**Why:** the license (`LICENSE-DEFINITIONS.md`) states the terms, the commit
history dates the work, and this block puts your name inside the file itself,
so it travels with every copy.
