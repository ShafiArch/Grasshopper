Add a card

Pick a Grasshopper file and the tool reads it here in the browser: the card gets an animation of the definition's own wiring diagram, every component and wire where you placed it. Prefer a drawn schematic instead? Pick one. Write the card text, download the update, and drag the files into the repository. Nothing on this page touches the repository by itself.

2. Animation

Choose a file above. Two animations are made from it: a geometry sketch assembled from the components it uses, and its wiring diagram.

Adjust the generated sketch

Or a drawn schematic. They all move; the chosen one is outlined, and the one the file's contents suggest is marked.

3. Card text
4. Save

The update contains the changed assets/site.js, an index.html with the cache number raised, the wiring diagram as graphs/<file>.json when that animation is chosen, and the .gh file itself if you chose one.

  1. Unzip the download.
  2. Open the repository on GitHub, click Add file, then Upload files.
  3. Drag in index.html, the assets and graphs folders and the .gh file. Commit.
  4. Wait a couple of minutes, then refresh the site.
