Edit a card

Rename a file, change a card's title, description, category or plugins, or remove a card. The animation stays as it is (use Add a card to change that). Download the update, drag the files into the repository, and delete the old file on GitHub when you renamed it. Nothing on this page touches the repository by itself.

1. Card

2. File name

3. Card text
4. Save

The update contains the changed assets/site.js and an index.html with the cache number raised. When you rename, it also contains the .gh under its new name (and its graphs/ json if the card uses the wiring animation).

  1. Unzip the download.
  2. Open the repository on GitHub, click Add file, then Upload files, and drag in everything from the zip. Commit.
  3. Delete the old file: open it on GitHub, click the three dots (or the trash icon), choose Delete file, and commit.
  4. Wait a couple of minutes, then refresh the site.
